# Assignment 03 — Employee Directory

An Employee Directory application built using React demonstrating state management (`useState`), event handling, and conditional rendering.

## Requirements & Fields Implemented
- **Employee Fields**: Name, Employee ID, Department Name, Gender, Phone Number, Local Address, Permanent Address.
- **Add Employee**: Modal form with client-side field validation.
- **Delete Employee**: Custom modal confirmation before deletion.
- **Edit Employee**: Inline editing of existing employee records.
- **Search Employee**: Real-time search by Name, ID, or Phone Number.
- **Employee Count & Department Filter**: Summary counter cards and department dropdown filter.
- **Empty State**: Fallback card view when search results yield no matches.

## Technologies Used
- React 18 (`useState`)
- Vite
- Lucide React (Icons)
- CSS Grid & Flexbox

## Installation & Running
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
