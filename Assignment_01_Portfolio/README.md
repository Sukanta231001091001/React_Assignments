# Assignment 01 — Personal Portfolio

A sleek, responsive personal portfolio web app built with React & Vite.

## Requirements Implemented
- **Header & Navbar**: Fixed top navigation bar with brand logo and navigation links.
- **Hero Section**: High-impact introduction with bio pills, call to action, and interactive avatar styling.
- **About Me**: Section highlighting background, passion, core engineering focus, and key traits.
- **Education**: Timeline component detailing degree, institutions, and certifications.
- **Skills**: Categorized tech stack breakdown featuring progress bars for proficiency.
- **Contact**: Interactive contact form with input validation and contact details.
- **Footer**: Responsive footer with copyright information.
- **Constraints**: Includes 8 custom React components, external CSS styling, clean JSX, and mobile-responsive layout.

## Technologies Used
- React 18
- Vite
- Lucide React (Icons)
- CSS3 (Variables, Flexbox, CSS Grid, Glassmorphism)

## Installation & Running
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
