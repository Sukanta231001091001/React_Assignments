# React Assignments Repository

This repository contains a collection of 11 React.js projects and assignments covering core to advanced React concepts, state management, routing, API integrations, context API, custom hooks, and interactive UI component development.

---

## 📁 Repository Overview

| # | Assignment Name | Description | Tech / Features |
|---|---|---|---|
| 01 | **Assignment_01_Portfolio** | Personal Portfolio Website | React components, Responsive Design, CSS |
| 02 | **Assignment_02_Student_Management** | Student Management System | Props, State, Filtering, Component Composition |
| 03 | **Assignment_03_Employee_Directory** | Employee Directory Application | Search, Filter, Modal Dialogs, CRUD operations |
| 04 | **Assignment_04_Weather_Dashboard** | Interactive Weather Dashboard | REST API integration, Async data fetching, Search |
| 05 | **Assignment_05_Shopping_Cart** | E-commerce Shopping Cart | Context API, `useReducer`, Cart calculations |
| 06 | **Assignment_06_Task_Manager** | Task Manager App | React Router v6, Protected Routes, Multi-page |
| 07 | **Assignment_07_Authentication_System** | Authentication & Authorization System | Auth Context, Login/Logout flow, Protected Dashboard |
| 08 | **Assignment_08_Expense_Tracker** | Personal Expense Tracker | Dynamic Charting (Recharts/Chart.js), Data Analytics, CSV Export |
| 09 | **Assignment_09_Blog_CRUD** | Full-Featured Blog CRUD Application | Axios / Fetch, JSON Server integration, Modal Forms |
| 10 | **Assignment_10_Movie_Search** | Movie Search & Discovery App | Custom `useDebounce` hook, OMDb API, Modal Preview |
| 11 | **Assignment_11_React_Dashboard** | Modern React Analytics Dashboard | Reusable KPI Widgets, Charts, Data Filtering, Order Table |

## 🚀 Getting Started

To run any of the assignments locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sukanta231001091001/React_Assignments.git
   cd React_Assignments
   ```

2. **Navigate to the specific assignment folder:**
   ```bash
   cd Assignment_01_Portfolio
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

## 🛠 Tech Stack

- **Framework:** React.js (Vite / CRA)
- **Styling:** CSS3, Modern Layouts (Flexbox/Grid), Responsive Web Design
- **State Management:** React Hooks (`useState`, `useEffect`, `useReducer`), Context API
- **Routing:** React Router v6
- **Tooling:** Vite, ESLint, Git, GitHub
