# Assignment 02 — Student Information Management

A student information portal built using React demonstrating component reusability and prop passing.

## Requirements Implemented
- **Components**: `App`, `Header`, `Footer`, `StudentList`, `StudentCard`.
- **Props Passing**: All student details (`name`, `rollNumber`, `department`, `semester`, `cgpa`, `photo`) are passed down explicitly through React Props.
- **Sorting Mechanism**: Interactive dropdown allowing CGPA sorting in ascending or descending order.
- **Filtering & Search**: Dynamic filtering by Department and search by Name/Roll Number.
- **Empty State**: Friendly fallback UI when search/filter returns zero records.

## Installation & Running
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
